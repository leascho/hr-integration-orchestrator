# Code of Conduct

## Our pledge

We are committed to making participation in this project a harassment-free experience for everyone, regardless of background or identity.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and focus on the work.
- Accept feedback gracefully and give it kindly.

## Unacceptable behavior

- Harassment, insults or discriminatory language.
- Publishing others' private information.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Report unacceptable behavior to the repository maintainers through a private channel (for example, a GitHub private security advisory or direct message to the maintainer). Maintainers may remove, edit or reject contributions that violate this code of conduct.

This code of conduct is adapted in spirit from the Contributor Covenant, version 2.1.
